### Задание 7: Практическая работа с httpbin

**Используйте httpbin.org для тестирования API:**

```bash
# GET запрос
curl https://httpbin.org/get

# POST запрос
curl -X POST https://httpbin.org/post \
  -H "Content-Type: application/json" \
  -d '{"name": "John"}'

# PUT запрос
curl -X PUT https://httpbin.org/put \
  -H "Content-Type: application/json" \
  -d '{"name": "John", "age": 30}'

# PATCH запрос
curl -X PATCH https://httpbin.org/patch \
  -H "Content-Type: application/json" \
  -d '{"age": 31}'

# DELETE запрос
curl -X DELETE https://httpbin.org/delete
```

**Задания:**
1. Выполните все запросы
2. Проанализируйте ответы
3. Проверьте статус-коды
4. Сравните тела ответов
