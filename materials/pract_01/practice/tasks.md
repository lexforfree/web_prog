### Задание 6: Практическая работа с curl

**Установите curl (если не установлен) и выполните запросы:**

```bash
# GET запрос
curl -v https://httpbin.org/get

# POST запрос с JSON
curl -v -X POST https://httpbin.org/post \
  -H "Content-Type: application/json" \
  -d '{"name": "John", "age": 30}'

# Запрос с заголовками
curl -v -H "Authorization: Bearer token123" https://httpbin.org/headers
```

**Задания:**
1. Проанализируйте вывод команды curl -v
2. Найдите в выводе: статус-код, заголовки ответа, тело ответа
3. Выполните запрос к httpbin.org/status/404 и проанализируйте ответ
4. Выполните запрос к httpbin.org/status/500 и проанализируйте ответ

### Задание 7: Создание простого HTTP-сервера

**Python (встроенный):**
```bash

```

**Node.js:**
```bash

```

**Задания:**

2. Откройте http://localhost:8000 в браузере
3. Создайте файл index.html и проверьте его отображение
4. Остановите сервер (Ctrl+C)
5. Попробуйте запустить на порту 80 (почему может не работать?)
