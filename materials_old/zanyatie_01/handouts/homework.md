### Задание 2: Реализация endpoints

Создайте следующие endpoints:

**Для Django:**
- `/` - возвращает "Hello, World!"
- `/about` - возвращает HTML-страницу с информацией о вас (ФИО, группа)
- `/time` - возвращает текущую дату и время

**Для FastAPI:**
- `GET /` - возвращает JSON `{"message": "Hello, World!"}`
- `GET /about` - возвращает JSON с информацией о вас
- `GET /time` - возвращает JSON с текущим временем

---

### Задание 3: Дополнительный endpoint (опционально)

Создайте endpoint с параметром:

**FastAPI:**
