### Задание 1: CRUD API для товаров (Products)

Создайте полноценный CRUD API для управления товарами.

**Модель Product:**
- id (автоинкремент)
- name (строка, 2-100 символов)
- description (строка, опционально)
- price (число, > 0)
- quantity (число, >= 0)
- category (строка)

**Endpoints:**
- `GET /products/` - список всех товаров
- `GET /products/{id}/` - детальная информация о товаре
- `POST /products/` - создание нового товара
- `PUT /products/{id}/` - полное обновление товара
- `PATCH /products/{id}/` - частичное обновление товара
- `DELETE /products/{id}/` - удаление товара

---

### Задание 2: Фильтрация и сортировка

Добавьте к endpoint `GET /products/` следующие возможности:

**Фильтрация:**
- `?category=electronics` - фильтр по категории
- `?price_min=100` - минимальная цена
- `?price_max=1000` - максимальная цена
- `?in_stock=true` - только в наличии (quantity > 0)

**Сортировка:**
- `?sort=price` - по цене (asc)
- `?sort=-price` - по цене (desc)
- `?sort=name` - по названию

**Пример:**
```
GET /products/?category=electronics&price_min=100&sort=-price
```

---

### Задание 3: Пагинация

Добавьте пагинацию к endpoint `GET /products/`:

**Параметры:**
- `?page=1` - номер страницы (по умолчанию 1)
- `?page_size=10` - количество на странице (по умолчанию 10, максимум 100)

**Ответ должен содержать:**
```json
{
  "items": [...],
  "total": 150,
  "page": 1,
  "page_size": 10,
  "pages": 15
}
```

---

### Задание 4: Валидация

Реализуйте валидацию данных:

**Обязательные поля:**
- name (2-100 символов)
- price (> 0)
- quantity (>= 0)

**Опциональные поля:**
- description (максимум 500 символов)
- category (максимум 50 символов)

**При ошибке валидации возвращать:**
```json
{
  "error": "Validation error",
  "details": {
    "name": "Name must be at least 2 characters",
    "price": "Price must be greater than 0"
  }
}
```
