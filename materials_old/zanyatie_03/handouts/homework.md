# Домашнее задание
## Занятие 3: Шаблонизация и рендеринг страниц

---

### Задание 1: Структура шаблонов

Создайте структуру шаблонов для блога:

```
templates/
├── base.html              # базовый шаблон
├── index.html             # главная страница
├── posts/
│   ├── list.html          # список постов
│   ├── detail.html        # детальная страница
│   └── form.html          # форма создания/редактирования
└── partials/
    ├── header.html        # шапка
    └── footer.html        # подвал
```

---

### Задание 2: Базовый шаблон (base.html)

Создайте базовый шаблон с:

- **HTML структура:** DOCTYPE, html, head, body
- **Блоки:**
  - `{% block title %}` - заголовок страницы
  - `{% block meta %}` - мета-теги
  - `{% block styles %}` - дополнительные стили
  - `{% block header %}` - шапка сайта
  - `{% block content %}` - основной контент
  - `{% block scripts %}` - JavaScript
  - `{% block footer %}` - подвал

- **Статические файлы:**
  - Подключите основной CSS файл
  - Подключите основной JS файл

- **Навигация:**
  - Ссылки на главную, список постов, создание поста
  - Используйте `{% url %}` тег

### Задание 3: Главная страница (index.html)

Создайте главную страницу с:

- **Hero секция:** заголовок, описание, кнопка
- **Последние посты:** карточки с 3 последними постами
- **Категории:** список категорий с количеством постов
- **Наследование:** extends base.html

---

### Задание 4: Список постов (posts/list.html)

Создайте страницу списка постов с:

- **Заголовок:** "All Posts"
- **Фильтрация:** по категории (ссылки)
- **Сортировка:** по дате (новые/старые)
- **Пагинация:** номера страниц, предыдущая/следующая
- **Карточки постов:** изображение, категория, заголовок, excerpt, автор, дата
- **Пустое состояние:** сообщение если постов нет

---

### Задание 5: Детальная страница (posts/detail.html)

Создайте детальную страницу поста с:

- **Заголовок:** название поста
- **Мета-информация:** автор, дата публикации, дата обновления
- **Изображение:** если есть
- **Контент:** полный текст поста
- **Теги:** список тегов
- **Кнопки:** редактировать/удалить (для автора), назад
- **Комментарии:** список комментариев, форма добавления

---

### Задание 6: Форма поста (posts/form.html)

Создайте форму для создания/редактирования с:

- **Поля:**
  - Заголовок (обязательно)
  - Категория (выпадающий список)
  - Краткое описание
  - Содержание (textarea)
  - Изображение (file upload)
  - Теги (через запятую)

- **Валидация:** отображение ошибок
- **Кнопки:** сохранить, отмена
- **Динамический заголовок:** "Create Post" или "Edit Post"
